# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues. 

Instead, please report them via the GitHub [Security Advisory](https://github.com/lyf-g/open-detective/security/advisories/new) feature if available, or contact the maintainers directly.
